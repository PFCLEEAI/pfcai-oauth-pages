# media

Publicly reachable image hosting for platforms whose APIs fetch media by URL
(Instagram and Threads fetch server-side and anonymously, so the file must be
readable without any authentication).

Files here are served at:
https://pfcleeai.github.io/pfcai-oauth-pages/media/<filename>

Anything placed here is public. Do not put drafts, client material, or anything
not intended for publication in this folder.
