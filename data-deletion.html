Data Deletion Instructions

Last updated: 2026-09-18

Who this page is for

This application is a private, single-user content-automation tool operated by PFCAI for its sole operator. It has no user accounts other than the operator's own, and it does not collect, store, or process personal data belonging to any other person. In practice, the only person who can have data held by this application is the operator.

What data exists

The application holds only the operator's own OAuth tokens and the content the operator has authored, both stored locally on the operator's machine. Nothing is transmitted to a third-party server, an analytics service, or a database operated by anyone else.

How to request deletion

To have any data associated with this application deleted, send a request to charilelee@pfcai.xyz stating the account involved. Requests are actioned manually and confirmed by reply.

The operator can also delete this data directly and immediately by revoking the application's access in the relevant platform's settings, which invalidates the stored token, and by deleting the local token and content files.

What deletion covers

  • Stored OAuth access and refresh tokens for the account in question.
  • Locally stored drafts, publishing records, and receipts referencing that account.

Because no data is held anywhere except the operator's own machine, deletion is complete once those local files are removed and platform access is revoked.

Note on this page

This page is the deletion instructions URL. It is a static page and does not itself receive or programmatically process deletion callbacks. Requests are handled manually at the contact address above.
