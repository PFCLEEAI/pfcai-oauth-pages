Last updated: 2026-09-18

What this page is

This is the uninstall landing page for a private, single-user content-automation tool operated by PFCAI. It is reached when the application's access to an account has been removed.

What happens when access is removed

Revoking the application's access on the platform immediately invalidates the OAuth token it held for that account. The application can no longer read from or publish to the account. The operator additionally deletes the corresponding local token file, after which no credential for that account remains anywhere.

Data

The application stores data only on the operator's own machine and sends nothing to any third-party server. To request deletion of anything associated with this application, see the data deletion instructions, or write to charilelee@pfcai.xyz.

Note on this page

This page is a static landing page. It does not itself receive or programmatically process uninstall callbacks; uninstall and deletion requests are handled manually at the contact address above.
