Privacy Policy

Last updated: 2026-09-18

Who operates this application

The application described by this policy is operated by PFCAI and is used exclusively by its sole operator. It is a private, single-user content-automation tool. It is not offered, sold, or made available to the public, and it has no user accounts other than the operator's own.

What the application does

The application authenticates, via OAuth, to social media accounts that belong to the operator - specifically LinkedIn, Meta Threads, and X. Its only function is to publish content that the operator has authored to those same accounts, and to read back basic status or metrics for the operator's own posts.

Whose data is involved

Only the operator's own account data is involved. The application does not collect, store, process, sell, or share personal data belonging to any other person. It does not request access to other people's accounts, contacts, friend lists, direct messages, or private content. Because the operator is the only user, there are no other end users whose data could be gathered.

Access tokens and credentials

OAuth access tokens and refresh tokens issued to the application are stored locally on the operator's own computer, in files readable only by the operator's user account. Tokens are transmitted only to the issuing platform's own API endpoints (for example, LinkedIn's or Meta's API) in order to perform the publishing actions described above. Tokens are never sent to, stored on, or shared with any third party, and there is no server-side component that receives them.

This website

This website consists of static pages hosted on GitHub Pages. It uses no analytics, no tracking pixels, no advertising, and no cookies, and it loads no external scripts, fonts, or other third-party resources. The OAuth redirect pages on this site display the current browser URL to the operator and copy it to the clipboard on request; they perform no network requests of their own and transmit nothing anywhere. As the site's host, GitHub may record standard server access logs; that processing is GitHub's and is governed by GitHub's own privacy statement.

Data retention

Access and refresh tokens are retained on the operator's machine only for as long as they are valid and in use. Expired tokens are discarded, and when the operator revokes the application's access on a platform - or stops using the application - the corresponding local token files are deleted. Content the operator drafts and publishes is kept in the operator's own private project files for as long as the operator chooses; it contains no other person's personal data. No data is retained anywhere else, because no data is sent anywhere else.

Changes to this policy

If the application's behavior changes, this page will be updated and the "Last updated" date above will be revised.
